3小时→3分钟，社区运营我自动化了

在基督城帮 CITANZ 办 meetup 两年，每场活动都要重复同一套体力活：
🎨 Canva 做海报 45 分钟
✍️ 一份文案改 5 个渠道 60 分钟
📍 场地一换，7 个地方要改
📊 手数 RSVP、写复盘

作为开发者，我决定只写一次。于是有了这个开源项目 citanz-meetup-generator：

✅ 一个活动 JSON → 两张品牌海报（排版自动校验，完全离线渲染）
✅ 自动生成领英 / 小红书 / meetup.com / 微信群×3 / Teams 的文案，各渠道字数限制直接卡死
✅ 发布靠"聊天"：跟 LLM 说一句"把区块链那场发到小红书"，skill 自己点按钮
✅ 活动结束还能写 recap + 复盘报告，每个数字都带来源

3 小时 → 3 分钟。运营上自动驾驶，判断力留给人。

MIT 开源，Node + Playwright + Claude Code，换个 config 就能给任何社区用。视频里展示的就是 8 月区块链那场的真实海报～

GitHub：GabrielPower1969/citanz-meetup-generator
